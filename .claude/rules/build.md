# Build configuration rules

The imperatives, for the moment you are editing one of these files. The *why*
behind each — and the traps that don't change what you type — is in
`docs/build-system.md`.

## Partition table

- `partitions.csv` is referenced from **BOTH** `board_build.partitions`
  (PlatformIO ignores the sdkconfig partition selection) and
  `CONFIG_PARTITION_TABLE_CUSTOM_FILENAME` (idf.py). Change one, change the other.
- **`history` is at offset 0x10000 and must stay there.** It sits before
  `factory` so a resize grows it upward and leaves written archive content in
  place; moving its start orphans years of data.
- Changing the table relocates the app, so that one upload must not be
  interrupted.

## Board macros

`ARDUINO_DFROBOT_FIREBEETLE_2_ESP32E` / `ARDUINO_XIAO_ESP32C6` (legacy names,
kept) derive from `IDF_TARGET` in `src/CMakeLists.txt`, **not** platformio.ini.
`THERMOMETER_C6_BOARD` selects the custom rev A PCB.

## platformio.ini

**Base sections must be plain sections, not `[env:...]`.** An `[env:...]` mixin
is itself a buildable, half-configured target, and `extends` only inherits
reliably from plain sections.

## sdkconfig

- Authored `sdkconfig.defaults[.<target>]` are tracked; generated
  `sdkconfig.<env>` are gitignored. Edit the former.
- **Reading a generated `sdkconfig.<env>` tells you what the build used; reading
  the authored defaults tells you what was chosen on purpose.** Don't quote a
  generated value as a project decision — several are IDF defaults that follow
  from another selection (worked example in `docs/build-system.md`).
- libc is pinned to newlib (`CONFIG_LIBC_NEWLIB`) deliberately. Don't switch to
  picolibc while PlatformIO drives the LP-core sub-build.

## Components and generated sources

- **Add the panel `.cpp` to `components/gxepd2/CMakeLists.txt` when enabling a
  new `USE_*` panel** — otherwise the link fails on a missing vtable that names
  nothing useful. Only the selectable panels are compiled.
- **Never name a project header like an IDF-internal one** — that collision is
  why it is `app_common.h`.
- **Don't modify `include/generated/`** — auto-generated by the font scripts and
  gitignored.
- Builds run with `-Werror`, so `#warning` fails the build. Use
  `#pragma message` for build-time notices.
